# Ignacio NutriApp · versión integrada 2.0

Aplicación Android/local-first para planificación y seguimiento familiar.

## Qué cambia
- Alimentos individuales: salmón, merluza, dorada, lubina, sardina, cilantro, ghee, manteca de cerdo ibérico, etc.
- Cada alimento tiene su propia ficha, frecuencia y propiedades nutricionales.
- Registro de consumo por alimento concreto; los objetivos semanales se actualizan a partir de los registros.
- Grupos desplegables y buscador alfabético.
- Consulta online por propiedad o alimento cuando la clasificación no sea suficiente.
- Seguimiento diario de ánimo, irritabilidad, frustración/rabietas, aleteo, conductas repetitivas, comunicación, respuesta al nombre, sueño, digestión y apetito/selectividad.
- Exportación de informe PDF legible.
- Sin publicidad ni SDKs de anuncios.
- Conserva el contenido profesional como fuente y distingue el catálogo ampliado.

## Importante
Las etiquetas de propiedades nutricionales son de organización/seguimiento. No convierten un alimento en un tratamiento médico y no sustituyen la indicación profesional.

## APK
En GitHub Actions se puede ejecutar `npm install`, `npm run build`, `npx cap add android`, `npx cap sync android` y `./gradlew assembleDebug`.
